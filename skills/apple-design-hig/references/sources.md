# Official sources

All guidance in this skill is paraphrased from these Apple sources (as of October 2026). Apple updates the HIG regularly — each page has a change log at the bottom. Most HIG pages also have a Markdown version: append `.md` to the page URL (e.g. `.../typography.md`).

**Human Interface Guidelines**
- Index: https://developer.apple.com/design/human-interface-guidelines/
- Design principles (reintroduced June 8, 2026): https://developer.apple.com/design/human-interface-guidelines/design-principles
- Foundations: …/accessibility, …/color, …/dark-mode, …/layout, …/materials, …/typography, …/sf-symbols, …/icons, …/app-icons, …/motion, …/writing, …/branding
- Patterns: …/patterns (feedback, loading, modality, onboarding, searching, settings, undo-and-redo, entering-data, accessing-private-data)
- Components: …/components (buttons, tab-bars, toolbars, sidebars, split-views, sheets, alerts, menus, lists-and-tables, search-fields)
- Platforms: …/designing-for-ios, …/designing-for-iphone-duo (new Sept 9, 2026), …/designing-for-ipados, …/designing-for-macos, …/designing-for-watchos, …/designing-for-tvos, …/designing-for-visionos, …/designing-for-games
- What's new: https://developer.apple.com/design/whats-new/
